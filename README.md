# human-to-code-translation

> 사람이 머릿속으로 푸는 방식 → 기계(Python/Java/C)가 실행하는 코드로, 그 **중간 다리**를 단계적으로 놓아주는 Claude Code / Codex 스킬.

알고리즘에서 진짜 어려운 건 "푸는 것"이 아니라, 사람이 자연스럽게 하는 일을 기계가 따라 할 수 있는 형태로 **번역**하는 것이다. 이 스킬은 그 번역을 6단계 파이프라인 + 매핑표로 일관되게 수행한다.

## 핵심 원리

코드는 갑자기 튀어나오지 않는다. 다음 순서로 번역된다:

```
말 → 손풀이 → 규칙(암묵지 명시화) → 변수/흐름 → 코드 → 트레이싱 검증
```

다리의 *의미*는 언어와 무관하고(같음), 달라지는 건 *문법*뿐이다. 그래서 같은 풀이를 C/Java/Python으로 나란히 보여준다.

## The Translation Pipeline

1. **사람 말로 다시 쓰기** + 손으로 풀 작은 예제 하나
2. **손풀이 관찰** — 답이 아니라 "내가 실제로 한 절차"
3. **암묵지 명시화** — "가운데를 본다" → `(low+high)//2`, 정수 나눗셈, off-by-one
4. **머릿속 상태 → 변수/자료구조** (매핑표 사용)
5. **반복·조건·종료 → 제어 흐름** (종료 조건 = 무한 루프 방지)
6. **코드로 받아쓰기 + 손 트레이싱 검증** (없는 값/맨 끝/빈 입력)

## 매핑표 (발췌)

| 사람의 머릿속 행동 | 기계 구성요소 |
|---|---|
| 기억해 둔다 | 변수 |
| 하나씩 본다 | `for` |
| ~인 동안 / ~할 때까지 | `while` + 종료 조건 |
| 지금까지 중 제일 ~ | 누적 변수 |
| 본 적 있나? / 중복인가? | set / dict |
| 최근 것부터 되돌린다 | 스택 |
| 양 끝에서 좁혀온다 | 투 포인터 |
| 표를 채워나간다 | DP 테이블 |

전체 표와 워크드 예제(이진 탐색, 스택, 해시, DP)는 [`SKILL.md`](./SKILL.md)와 [`worked-examples.md`](./worked-examples.md) 참고.

## 설치

Claude Code:

```bash
git clone https://github.com/cskwork/human-to-code-translation-skill.git \
  ~/.claude/skills/human-to-code-translation
```

`description`의 트리거(예: "머릿속으론 풀리는데 코드가 안 써져", 알고리즘 문제를 코드로 옮기기, off-by-one/무한루프)가 잡히면 자동으로 로드된다.

## 누구에게

- 알고리즘/코딩테스트를 **가르치는** 사람 (입문자에게 "왜 이 코드가 이렇게 되는지" 설명)
- "사람으로는 풀겠는데 코드로 못 옮기겠다" 는 학습자
- 경계/종료 조건(off-by-one, 무한 루프)에서 자꾸 막히는 사람
